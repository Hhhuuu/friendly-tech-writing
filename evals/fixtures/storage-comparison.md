# Выбор хранилища для отчётов

В современном мире существует множество различных вариантов хранения данных, каждый из которых обладает своими преимуществами и недостатками. В целях принятия эффективного решения была сформирована нижеследующая таблица.

| Вариант | Чтение p95 | RPO |
| --- | ---: | ---: |
| PostgreSQL | 45 мс | 5 минут |
| Redis | 8 мс | Данные теряются при сбое |
| S3 | 180 мс | 24 часа |

Команда склоняется к PostgreSQL, потому что потеря данных при сбое недопустима, а RPO 24 часа не подходит. Нагрузочный профиль ещё не измеряли.
