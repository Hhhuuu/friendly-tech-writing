# Настройка агента

Настоящий документ определяет порядок осуществления настройки данного программного продукта.

## Требования

Для обеспечения корректного функционирования требуется наличие Python 3.12. Также пользователю надлежит осуществить проверку доступности порта 9120.

## Запуск

Для осуществления запуска необходимо выполнить `agentctl start --port 9120`. После выполнения вышеуказанной команды требуется произвести проверку `/healthz`.
